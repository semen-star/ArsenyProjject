Как пользоваться картой

Для реализации полноценной интерактивной карты:

  1. Зарегистрируйтесь на Яндекс.Карты API или Google Maps Platform
  2. Получите API-ключ
  3. Раскомментируйте строку подключения API в секции <head> этого файла
  4. Замените заглушку в функции initMap() в файле script.js на реальный код карты
  5. Добавьте координаты реальных объектов Магнитогорска

Пример координат для Магнитогорска: 53.407° с.ш., 58.979° в.д.
